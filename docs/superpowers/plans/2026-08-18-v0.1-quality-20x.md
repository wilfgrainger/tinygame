# TinyWorld V0.1 20x Quality Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the existing V0.1 slice dramatically better to control, explore and inhabit on Android without adding new feature families.

**Architecture:** Keep the existing PlayCanvas/Vite/Worker architecture. Move quality logic into small pure helpers or focused render modules, preserve current persistence/API contracts, and use TDD for behavioural changes. Human visual/gameplay acceptance remains mandatory.

**Tech Stack:** TypeScript 7, Vite 8, PlayCanvas 2.21, Vitest 4, Playwright 1.61, Cloudflare Worker + D1.

**Spec:** `docs/superpowers/specs/2026-08-18-v0.1-quality-20x-design.md`

## Global Constraints

- No new feature families, jobs, shops, vehicles, missions, multiplayer, economy or persistence domains.
- Android landscape is the primary acceptance target; portrait remains mechanically correct.
- Left stick is camera-relative; moving avatar faces travel direction; right drag controls camera independently.
- Roads/paths remain terrain-following and traversal limits remain enforced.
- Keep Cloudflare Free-plan architecture and current distribution budget.
- No per-frame network traffic.
- Real Android and family acceptance override CI.
